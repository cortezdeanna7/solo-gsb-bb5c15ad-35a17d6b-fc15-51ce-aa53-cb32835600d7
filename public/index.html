家谱关系核对

录入成员与「父母 → 子女」关系（每名子女至多两位父母），自动拒绝自指、重复边与祖先环路； 每次成功写入都可在顶部「最近操作」中一键撤销（重启后仍可撤销，仅可撤销一次）； 选中两人即可沿父母链查询总代数最少的全部共同祖先及最短亲缘路径； 还可一键核查全部「辈分矛盾」：同一对祖先与后代沿不同路径的最少 / 最多代数不一致时逐条列出； 成员列表每行的「删除影响」可在删除前预览：服务端以当前家谱构造只读假设图移除该成员及其亲子关系， 逐对列出原本可达而删除后不可达、以及仍可达但最短代数增加的祖先→后代成员对（各附变更前后一条最短成员链）； 「变更影响预览」可在不落盘的假设图上试算新增 / 移除一条关系前后辈分矛盾的逐对变化； 「备份与恢复」可下载仅含成员 ID、姓名、纪念日与关系的 JSON 备份，选择备份文件预览校验后整体恢复（可撤销）； 「成员纪念日」可为每名成员登记一个生日与一个忌日（公历月日），并查看包含今天在内的未来 30 天纪念日清单； 「后代支系视图」可选择始祖与 1～10 代上限提取后代：同一后代只显示一次、按最短代数分组并标记所属分支， 仅展示支系内亲子关系，结果可下载为局部导出的 JSON； 「整谱关系图」把全部成员与父母→子女关系绘成可缩放的分层 SVG（按连通分量分组、最长父母链分层， 图上标注生成时的家谱版本），可下载，整个模块只读； 「关键连接」把全部关系视为无向连接，按家族分别找出「移除单条就会拆开其家族」的桥梁关系， 逐条展示断开后原家族两侧的成员数与姓名（只读，标注所依据的家谱版本）。

最近操作

每次成功写入都会保存变更前的完整家谱作为唯一可撤销快照（重启后仍可撤销）； 撤销会恢复成员 ID、姓名、纪念日与全部关系原貌、推进版本并清空快照，只能撤销一次。

① 成员 0/30

    合并重复成员

    成员不足两人时无法合并。选择「保留成员」与「被合并成员」后点击「预览合并」： 被合并成员在全部关系中的 ID 将被替换为保留成员并自动去重； 若产生自指、某子女超过两位父母或祖先环路，会逐项列出冲突并禁止提交。预览不会修改家谱。

    删除影响预览

    点击「① 成员」列表中某位成员行内的「删除影响」，服务端以当前家谱构造不落盘的只读假设图： 移除该成员本身及与其相连的全部父母→子女关系，仅比较删除后仍在谱中的有序祖先→后代成员对。 列出两类影响：删除后不可达（原本的唯一通路经过该成员，删除后成员链为空）与 最短代数增加（仍有替代路径但必须绕远，附增加代数与变更前后各一条最短成员链）； 多路径按最短代数判定，仍有同代替代路径的成员对不会误报为断联。 预览只读、不写家谱；结果标明所依据的家谱版本，家谱发生写入后会标记过期并提示重新预览。 现有的「删除」与顶部「撤销」入口不受影响、继续可用。

    在「① 成员」中点击某位成员的「删除影响」查看预览。

            从备份恢复

            选择本工具下载的 JSON 备份后点击「预览恢复」：服务端按 30 人上限、每名子女至多两位父母、 无自指 / 重复关系 / 祖先环路对整份文件逐条校验，重复 ID、缺失端点或非法关系会逐项列出， 预览不修改家谱。确认恢复将整体替换当前家谱（版本 +1，可经「最近操作」撤销）； 若预览后文件被调换或家谱被修改，确认会被拒绝并要求重新预览。

            ⑧ 后代支系视图

            沿「父母 → 子女」关系提取所选始祖的后代：同一后代经多条路径到达时只显示一次， 按距始祖的最短代数分组，并标记其所属的每个始祖直系子女分支； 仅展示两端都在支系内的亲子关系，不带入支系外成员。 下载的 JSON 是局部导出（成员 ID、姓名、代数、所属分支与支系内关系），不是整谱备份； 成员或关系变更后旧结果会标记过期，重新生成即按最新状态计算。

            选择始祖与代数上限后点击「生成支系视图」。

            ⑨ 整谱关系图

            把当前全部成员与「父母 → 子女」关系绘成一张可缩放的分层图：先按忽略方向的关系划分连通分量 （分量之间留白），各分量按最长父母链分层；多位父母指向同一子女时只绘一个成员节点并保留各条连线。 图上标注生成时的家谱版本；整个模块只读，家谱写入后请重新生成。可拖动平移、滚轮或按钮缩放。

            点击「生成整谱关系图」查看当前家谱的整体结构。

            ⑩ 关键连接

            把当前全部成员与「父母 → 子女」关系视为无向连接：先按忽略方向的连通分量 （原本互不连通的家族）分组，再在各家族内部分别找出桥梁关系—— 移除这一条关系就会把原来连通的家族拆成互不相连的两部分。逐条展示关系两端、所属家族， 以及断开后原家族两侧的成员数与姓名；两端之间仍有其他连接路径的关系不会误报。 结果标注所依据的家谱版本，家谱写入后请重新计算；整个模块只读。

            点击「查找关键连接」找出移除后就会拆开其家族的关系。
